# Product demo proof

## Establish the evidence boundary

Identify the intended audience, platform, aspect ratio and real feature to demonstrate. Inspect the authorized running product before writing strong claims. Static source, a mockup and a real completed user flow are different evidence.

Label AI illustrations, prototypes, fictional customers and sample data when they could be mistaken for actual product proof. Never invent customers, revenue, performance measurements, certifications or partnerships.

## Story with a concrete payoff

Use the first few seconds for a sharp problem, contrast, result or question. Avoid a long greeting or generic technology introduction. Build around one buyer-visible outcome and show the actual action that produces it.

Strong copy is welcome when it describes demonstrated behavior. Claims about success rate, profit, scale or time saved require measurements; otherwise use a clearly stated test/demo/target formulation.

## Capture and build

Use authentic UI/screens from the current app, not AI-generated screens presented as its interface. Hide personal data and credentials before capture. Preserve meaningful context so the audience can understand the operation.

Match narration, highlights and subtitles to actual events. Keep a readable type hierarchy and platform-safe framing. Music must not bury the message; disclose material limits without turning the entire video into fine print.

## Export acceptance

Open the final exported file and verify aspect ratio, playback, voice/music mix, subtitle refresh, black frames and a deliberate ending. Project creation, preview and render submission are intermediate states.

Provide the playable final file and requested editable assets. If a screenshot is requested, attach an actual image the user can see; a repository link is not a screenshot. If delivery display fails, correct the handoff rather than repeating that it is “above.”

Acceptance example: a demo shows a real interaction and resulting output; illustrative B-roll is labeled, and the final MP4—not just the timeline—was checked.
